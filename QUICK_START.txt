TRAFFIC ACCIDENT MAP - QUICK START
==================================

Website files:

1. index.html
   Open this through GitHub Pages or a local web server.

2. styles.css, src/i18n.js, src/app.js
   Static app assets loaded by index.html.

3. accidents.json.gz
   Compressed dataset loaded by the browser.

4. decompress-worker-json.js
   Web Worker that decompresses the dataset.

5. accidents.csv
   Processed CSV used to regenerate accidents.json.gz.

6. data/pnYYYY.csv
   Raw Slovenian Police CSV files.

Run locally:

  python3 -m http.server 8000

Then open:

  http://localhost:8000

Setup:

  python3 -m pip install -r requirements.txt

Common commands:

  # Merge raw data files into accidents.csv.
  python3 manage_csv.py merge data accidents.csv

  # Merge all available raw data years.
  python3 manage_csv.py merge data accidents.csv --all-years

  # Merge specific years or year ranges.
  python3 manage_csv.py merge data accidents.csv --years 2024 2025
  python3 manage_csv.py merge data accidents.csv --years 2020-2025

  # Convert one raw CSV file to a processed UTF-8 CSV with WGS84 coordinates.
  python3 manage_csv.py convert data/pn2025.csv

  # Validate the processed CSV.
  python3 manage_csv.py validate accidents.csv

  # Print quick statistics.
  python3 manage_csv.py stats accidents.csv

  # Regenerate the compressed JSON used by the website.
  python3 csv_to_json.py accidents.csv accidents.json.gz

Recommended update flow:

  python3 manage_csv.py merge data accidents.csv
  python3 manage_csv.py validate accidents.csv
  python3 csv_to_json.py accidents.csv accidents.json.gz

Deploy:

  git push origin main

CSV notes:

  The processing script reads raw CSV columns as text so values such as
  08.10, 00055, and 06 keep their original formatting.

  The script converts D96/TM coordinates from GeoKoordinataX and
  GeoKoordinataY to WGS84 latitude and longitude.

  The map dataset is one row per accident, not one row per participant.
  See DATA_NOTES.md for source, limitations, privacy, and attribution notes.
